# Structural fusion gradient blockage: root-cause diagnosis and controlled correction

**Confirmed implementation issue:** `GeometryBranch.final[-1]` is initialized with zero weight and zero bias. `StructuralCrossAttention.project` has very small weights. On a real AlphaFold engineering graph and synthetic input tensors, the initial structural residual is exactly zero, causing the attention values to be zero and preventing first-step gradients from reaching attention and upstream GVP parameters. A diagnostic recorded 92 parameter tensors with zero gradient, 24 unused/no-gradient tensors, zero attention output projection gradient, and zero first GVP gradient. This is a staged/blocked initialization, not proof that all those parameters remain frozen forever: later updates can unblock them.

An **opt-in** correction initializes the geometry final projection with Gaussian std 0.01 and attention output projection with Gaussian std 0.05. On the same graph/input/seed, the initial structural output delta becomes nonzero (~0.0001009 max absolute), zero-gradient tensor count drops to 0 among parameters with gradients, and GVP, attention, and output projections receive nonzero gradients. Regression test: `python tests_v4/structural_gradient_unblocking_test.py`. The legacy production defaults are unchanged; the correction is isolated to a development training script.

**Training result:** using frozen numeric-only sequence seed 2103 and 106 numeric-Kd training pairs, four epochs of opt-in corrected geometry training at lr 3e-4 yield numeric-Kd validation pooled RMSE 1.0216843 (epoch 1) and 1.0216993 (epoch 4) versus **1.0216839** for the same frozen sequence baseline on 71 measured-affinity validation pairs. Thus, restored gradient flow **does not** yet improve predictive performance. A prior high-gain geometry variant worsened numeric-Kd RMSE to 1.064493 by epoch 4.

The development validation has been inspected repeatedly, the protein family split is not independent, and assayed constructs remain unverified. Do not describe the gradient fix as an accuracy win. The model may need better structural supervision, longer controlled training, or an explicitly gated path, but any such claim needs a new independently approved cohort and negative controls.
